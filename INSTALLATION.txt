1. Extraire les fichiers de cette archive dans C:\xampp\htdocs\CivLink (fusionner les dossiers). Seuls index.php du FrontOffice et includes/navbar.php remplacent des fichiers existants. Sauvegarder ces deux fichiers avant de les remplacer. Si vous les avez personnalisés, reporter uniquement les changements de liens et le script session du navbar.
2. Dans XAMPP, démarrer Apache et MySQL. Aller sur http://localhost/phpmyadmin/ puis Importer, choisir database_auth.sql et Exécuter. La base civlink_auth est indépendante des éventuelles bases existantes.
3. Ouvrir http://localhost/CivLink/ et cliquer Créer un compte ou Connexion.
Configuration locale: MySQL 127.0.0.1:3306, root sans mot de passe (modifier Models/Auth.php si différent). Ne pas utiliser ces identifiants en production. Les inscriptions créent uniquement des citoyens. Les sessions ne protègent pas encore les autres modules. Pas de récupération de mot de passe, ni vérification e-mail, ni CRUD administrateur dans ce lot. Le SQL crée les deux tables Utilisateur et Role. Le blocage des tentatives est limité à la session et n'est pas une protection de production.
